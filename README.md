# Rox Free Chat

Cross-platform Flutter starter for Android + iPhone.

## Included
- Login/register screen
- Chat list
- One-to-one chat UI
- Profile screen
- Admin dashboard UI
- User/content/report controls
- Firebase-ready architecture notes

## Run
1. Install Flutter.
2. `flutter pub get`
3. Connect Firebase for real authentication, database, storage and notifications.
4. `flutter run`

This is an MVP UI/prototype; production messaging, authentication, moderation and payments need a backend such as Firebase.
